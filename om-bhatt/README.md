# Om Bhatt (Member 1): Prompt Design, Testing, Refinement

Put your files in this folder. Commit often, because commit timestamps are our prompt history.

## What goes here
- `prompt_v1.md`, `prompt_v2.md`, `prompt_v3.md`: one file per prompt version (system prompt, user prompt, few-shot examples).
- `changelog.md`: for each version, what changed, why, and the result.
- `judge_prompt.md`: the prompt used to grade answers as hallucinated or not.
- `failures.md`: failure cases found and how each was fixed.

## Rules
- Never overwrite an old version. Add a new file instead.
- Every version must state which prompting techniques it uses (we need at least two).
- You must be able to explain every prompt live to the judges.
